# 📝 Summarizerly AI

An intelligent offline document summarization tool that extracts and summarizes content from multiple file formats including PDFs, documents, images, audio, and video files using AI models.

## ✨ Features

- **Multi-Format Support**: Process PDFs, Word documents, PowerPoint presentations, text files, images, audio, and video
- **Offline Processing**: Works completely offline after initial model download
- **AI-Powered Summarization**: Uses T5-small transformer model for intelligent text summarization
- **OCR Capability**: Extract text from images using Tesseract OCR
- **Audio/Video Transcription**: Transcribe audio and video files using OpenAI Whisper
- **User-Friendly Interface**: Clean Streamlit web interface for easy file uploads and processing

## 🎯 Supported File Formats

- **Documents**: PDF, DOCX, PPTX, TXT
- **Images**: JPG, PNG, JPEG
- **Audio**: MP3, WAV
- **Video**: MP4, MKV, AVI

## 🚀 Getting Started

### Prerequisites

Before running the application, install these external tools:

#### 1. Tesseract OCR (For Image Text Extraction)
- Download from: [UB Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki)
- Install to `C:\Program Files\Tesseract-OCR`
- Add `C:\Program Files\Tesseract-OCR` to your System PATH environment variable

#### 2. FFmpeg (For Audio/Video Processing)
- Download from: [ffmpeg.org](https://ffmpeg.org/download.html)
- Extract the zip file
- Add the `bin` folder (containing `ffmpeg.exe`) to your System PATH environment variable

### Installation

1. Clone the repository:
```bash
git clone https://github.com/phani-18-coder/Summarizerly-AI.git
cd Summarizerly-AI
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

### Running the Application

Start the Streamlit application:
```bash
streamlit run app.py
```

The application will open in your default web browser at `http://localhost:8501`

## 📖 Usage

1. **Upload File**: Click "Browse files" and select your document, image, audio, or video file
2. **Processing**: Wait for the system to extract text from your file
3. **View Extracted Text**: Optionally expand the "View Extracted Text" section to see the raw extracted content
4. **Generate Summary**: Click the "Summarize" button to generate an AI-powered summary
5. **Review**: Read your concise summary generated by the T5 model

## 🛠️ Technology Stack

- **Frontend**: Streamlit
- **AI Models**: 
  - T5-small (Text Summarization)
  - OpenAI Whisper (Audio/Video Transcription)
- **Text Extraction**:
  - pypdf (PDF processing)
  - python-docx (Word documents)
  - python-pptx (PowerPoint presentations)
  - pytesseract (OCR for images)

## ⚙️ Configuration

If Tesseract is not in your PATH, you can manually set the path in `src/extractors.py`:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

## 📝 Notes

- **First Run**: The first time you run summarization or audio transcription, the AI models will be downloaded automatically. This may take a few minutes depending on your internet speed.
- **Performance**: Audio/video processing may take some time on CPU. For faster processing, consider using a GPU-enabled setup.
- **Model Size**: T5-small (~240MB) and Whisper-base are lightweight models optimized for CPU usage.
